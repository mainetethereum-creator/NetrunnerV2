Восстановление: База → MASTER → JSON экспорт / импорт → Импорт файла JSON →
выбрать этот файл. После проверки нажать «Сохранить».

Расстановка редактора автоматически загружается при входе на Базу в режиме разработки.
Она не меняет исходную сцену для production. Сохранение и экспорт заблокированы,
пока карта восстанавливается или если её загрузка не удалась.

Поезд и эстакада являются частью сцены в коде, а не JSON редактора. Их модели:
`public/base/models/elevated-rail-v2.glb`; Blender-исходник:
`output/elevated-rail/v2/cyberbase-elevated-rail-v2.blend`.
Выбранная камера сохраняется отдельно в браузере и не входит в экспорт карты.
